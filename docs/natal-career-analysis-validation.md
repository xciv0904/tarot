# 人生主題事業分析：修正與驗證

本次修正在既有本命盤分析管線內完成，沒有改動天文計算、宮位制、相位容許度、題目 ID、命盤／歷史儲存格式或 UI 樣式。未部署。

## 根因與完整追蹤

修改前的檔案／函式與實際證據見 [根因與範圍](natal-career-analysis-scope.md)。工作內容過度依賴單一行星固定句；能力題先算語意分數，後續 knowledge planner 卻再次覆寫成行星模板。三題各有 ID，但沒有獨立的職涯候選評分。原始六盤結果見 `tests/reports/natal-career-before.json`。

目前六張測試盤並未全部產生使用者所列的相同四項，原始碼也未找到那四個逐字標籤。因此不把「固定四項陣列」或「快取錯盤」當作已證實的原因。此次直接修正已重現的資訊壓縮與結論覆寫，沒有用同義詞、亂數或輪替模板製造差異。

## 核心邏輯

- `NatalCareerAnalysis.profile(chart, unknownTime)`：只讀既有計算結果。MC、十／六／二宮宮頭、宮內行星、現代宮主星的落座／落宮、水星／火星／土星等個人工作方式及相關主要相位，映射到 12 維向量。
- 12 維：主動推進、結構與持續、邏輯分析、創作發想、資訊表達、需求照顧、帶領與代表、變動與探索、深入追查、獨立自主、精準核對、資源衡量。負值表示相反工作方式，缺少資料不等於個人能力低。
- 工作任務、環境、優勢使用三組來源權重。十宮／MC 在任務較重；六宮／六宮主星在環境較重；個人行星在能力較重。不是先挑職能再反推環境與優勢。
- MC／宮頭相同星座合併，以各通道最大權重計算。單一行星同時有多種角色也只取最大關聯權重，不把重複 indicator 當成多筆獨立證據。
- 行星特徵 = 0.75 × 落座向量 + 0.25 × 行星功能；已知時間時再加 0.25 × 實際落宮的領域向量。MC／宮頭直接用落座向量。個人行星與相關宮位各依不同通道權重形成來源貢獻。
- 宮主星沿用本站 `natalHouseRulerKey`／`SIGN_RULER_MODERN`，沒有混入其他系統或新設守護星。
- 主要相位只讀 `chart.aspects`，至少一端必須是職涯來源；依原有容許度和實際 orb 加權。和諧相位有限支持，張力相位以 0.65 倍反向修正並標記整合成本；不當成能力缺陷。重複相位去重。
- 工作任務候選有 12 類，每類使用不同正負係數。總分 = Σ來源 dot(該通道來源向量, 該候選係數)。沒有統一底分、隨機推薦或固定四項。只列正分且達首位 55% 的至多三項；前兩項差距小於 15% 時說明接近。
- 環境六軸獨立比較兩端，偏好強度為 abs(合計貢獻) / Σabs(各來源貢獻)。低於 0.18 不強迫選邊，明列需保留切換空間。其餘明列偏好及相反條件的適應成本。
- 優勢比較 10 種行為模式，列主要與次要／並列優勢及主要行為過度使用時的盲點。
- 三題經同一個既有 Question Contract 品質檢查，沿用既有兩個 detail 區塊和 caution，避免環境六軸／次要優勢被 UI 的 `slice(0,2)` 隱藏。
- 既有「為什麼這樣說？」顯示對應配置；專業模式的診斷保留每一維、候選係數、來源正負貢獻、總分與版本。命盤指紋補入宮頭與相位，analysisKey 加入選題集合。

這些數值是公開可追溯的本站詮釋規則，並非占星學通用量表、科學驗證能力分數、工作勝任度或就業機率。
